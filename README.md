**The Look Ecommerce — SQL Practice**

This repository contains my SQL practice using the Looker Ecommerce dataset in Google BigQuery.
I'm using this dataset to learn SQL and explore e-commerce data, from basic queries to analyzing orders, products, and customers.

**Topics Covered**
Basic queries: SELECT, WHERE, ORDER BY, and LIMIT
Filtering unique values with DISTINCT
Aggregate functions: COUNT, SUM, AVG, MIN, and MAX
Grouping data with GROUP BY
Joining tables with INNER JOIN and LEFT JOIN
Exploring order status, product popularity, customer distribution, and sales metrics

**Tools**
Google BigQuery
SQL

**Dataset**
The Look Ecommerce — BigQuery Public Dataset
